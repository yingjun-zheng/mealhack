## 作品说明（完整版，约 400 字）

**MealHack · 套餐黑客**

麦当劳套餐里的每一项都是可替换的。一个「麦辣鸡腿汉堡三件套」有 154 种合法组合，实付价格从 32 元到 46 元相差 14 元——这个空间一直摆在菜单上，但人脑在点餐的 30 秒里不可能穷举完。

MealHack 做的事情很简单：把它算完。

程序通过麦当劳 MCP 读取套餐的槽位与可替换项，枚举全部组合，再调用官方 `calculate-price` 逐一真实核价（不下单、不花钱、不占库存），最后输出**价格-蛋白质的帕累托前沿**——一条「每一点都无法被更便宜且蛋白更高的方案替代」的边界。再用最大弦距法找出拐点，并给出**边际收益表**：每多花 1 元能换多少克蛋白质，断崖出现在哪一段。

真实结果：默认搭配 33.50 元 / 921 kcal / 蛋白 28g；拐点方案 36.00 元 / 993 kcal / 蛋白 37g。而 32→33 元这一段，1 块钱能换 7 克蛋白；36→44.5 元这一段，8.5 块钱只换 2 克。

**与常见的「省钱助手」的区别**：那些工具是让 LLM 凭菜单文字推荐一个搭配，结果不可验证。MealHack 输出的是可行域的边界，每一点都能被官方接口复算，抽样核价一致率 100%。

技术上零第三方依赖（纯 Python 标准库），含一个自包含的交互式可视化网页，并封装为 WorkBuddy Skill 可直接对话调用。开发过程中记录的 6 个 MCP 接口坑（含一个会静默返回错误价格的接口行为）已整理成文档公开。

## 使用说明（如果表单要填运行方式）

在线直接体验：https://yingjun-zheng.github.io/mealhack/

本地运行：

```bash
export MCD_MCP_TOKEN="你的 token"          # 申请：https://open.mcd.cn/mcp
git clone https://github.com/yingjun-zheng/mealhack.git
cd mealhack
python src/solve.py --meal 9900005456      # 求解并核价
python src/build_web.py                    # 生成可视化网页
python src/pareto.py                       # 离线算法自测，无需 token
```

需要 Python 3.10+，无第三方依赖。
